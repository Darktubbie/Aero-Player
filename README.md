🌊 Aero Player

«A lightweight, local-first music player for Android with a Frutiger Aero soul.»

Aero Player is an open-source Android music player focused on making local music feel fresh, simple, and fun again.

Built from the ground up as a native Android application, Aero Player combines a modern audio engine with a visual style inspired by the Frutiger Aero era, classic Windows Aero interfaces, and the colorful digital aesthetics of the late 2000s and early 2010s.

«🚧 Aero Player is currently in early development.
The repository is being built from scratch and many features are not available yet.»

---

🌊 Vision

Aero Player is designed around a simple idea:

Your music should belong to you.

The core experience is local-first. Your music library, playlists, settings, and playback experience should work directly on your device without requiring an account or an always-online connection.

Online features may be added later as optional extensions rather than becoming a requirement for the basic player.

---

✨ Planned Features

🎵 Music Library

- Scan music from folders on your device
- Album, artist, and song views
- Search and sorting
- Album artwork and metadata
- Support for common music formats
- Fast local library database

▶️ Playback

- Background playback
- Lock-screen controls
- Notification controls
- Play / pause / previous / next
- Seek controls
- Shuffle and repeat
- Playback queue
- Media controls for Bluetooth devices

📚 Playlists

- Create and manage playlists
- Favorites
- Reordering
- Import/export
- Local backups

🌐 Optional Online Features

Aero Player may eventually support optional online music discovery through independent providers.

The local player will remain usable without these services.

🎨 Aero Interface

- Frutiger Aero-inspired visual identity
- Glass and translucent surfaces
- Soft gradients
- Water, sky, and nature-inspired elements
- Smooth animations
- Responsive layouts for phones and larger screens
- Light and dark themes

---

🛠️ Technology

Aero Player is planned as a native Android application using:

Technology| Purpose
Kotlin| Application language
Jetpack Compose| User interface
Android Media3| Audio playback
Room| Local music library and data
Storage Access Framework| User-selected music folders
GitHub Actions| Automated builds

The project is intentionally being built as a native application rather than as a WebView wrapper.

🌱 Design Philosophy

Aero Player takes inspiration from an era when software interfaces were allowed to be colorful, expressive, glossy, and playful.

The goal isn't to recreate an old operating system.

Instead, Aero Player takes the spirit of that era and combines it with modern Android design and usability.

Glass. Water. Sky. Light. Music.

🌊 🫧 ☁️ 🎵

---

🔒 Privacy

Aero Player is designed with a local-first approach.

The basic music-player experience should not require:

- An account
- Cloud storage
- A subscription
- A mandatory internet connection

Online functionality, if introduced, will remain separate from the core local playback experience.

---

📦 Building

Aero Player is intended to be built automatically using GitHub Actions.

Every development build will eventually be available as an APK artifact from the project's Actions workflow.

Release builds will be distributed through GitHub Releases.
